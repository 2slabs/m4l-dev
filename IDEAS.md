# Ideas (not built)

## Noise and field recording device (2026-10-15)

A separate 2sl Max for Live device for the hiss, noise and field recordings under Deepchord-style
dub techno, so the drum machine (and stab) stay clean voices. Scope not decided yet.

## Sampler emulation device (2026-10-15)

A separate 2sl audio effect that you put on anything: a menu of classic samplers (starting with
Modell's Akai S900, references/drums/production.md), each emulating that machine's sample rate,
bit depth, converters and filters. Not started; each machine's specs need sources first.
