# 2sl drums: plan (2026-10-15)

A 909-style drum machine for Max for Live with its own gen~ voices, for sleepy, lo-fi dub techno
in the Deepchord / Echospace vein (not Basic Channel / Maurizio punch). Its main job is trying
patterns: canned patterns, rerolls, variations. Sources: references/drums/.

## Decided (with the user)
- Voices are synthesized in gen~, generated by a Python script like 2sl stab.
- Pages, like stab.
- An effect goes on the device that makes the sound it changes: bit reduction on drum sounds is
  here; hiss, noise and field recordings are a separate device (IDEAS.md).
- Built on the `drums` branch (worktree m4l-dev-drums), parallel to the ongoing stab work.

## What the sources say that shapes the design
- Modell: kick and bass go in last, "just a metronome" for the ambient layers; only percussion
  and bass are quantized (production.md). The kick serves; it is not the feature.
- No sourced Deepchord / Echospace drum grid, tempo or drum machine exists (README.md, gaps).
  Canned patterns come from the sourced dub techno / minimal / Detroit grids (patterns.md P1-P11)
  and the Mutable Grids map (P12, GPLv3).
- Grids' variation engine is code, so it can be reused exactly: per-step levels 0-255, density is a
  threshold, randomness perturbs the levels each pass, level > 192 = accent (patterns.md B1).
- Other variation tools, sourced: Elektron probability / FILL / A:B conditions (B2), the 909's own
  accent, 7-level shuffle, flam and 1-16 steps (B4), producer practice (B5).

## Pattern engine (the core)
- Style -> a set of canned kit patterns. Generate = a new kit pattern; per-voice reroll; lock a row.
- Variation 0 = repeats exactly; higher = Grids-style perturbation + phrase-end fills (A:B
  conditions at 4 / 8 bars).
- Swing = the 909 shuffle; density = Grids threshold; click a step to edit, as in stab.
- Designed so it could become one shared pattern engine with chord-progressions, bassline and
  stab's machine later (4 parallel pattern engines today).

- Live only: no write-to-clip.
- The kick can go soft and round as well as 909.
- Shared kit: copy stab's helpers now; the SHORTCUTS.md entry may outlive 24 h until the stab work
  lands, then stab is folded onto the kit.
- First an intermediate device to try in Live; the kick gets fixed up after.

## Open
- Voice circuit disagreements (README.md): BD oscillator (saw + waveshaper vs triangle + diode),
  BD Tune (pitch vs sweep depth vs sweep decay), noise register, cymbal clock. Most envelope
  times and Hz are unsourced; the schematics are scans. Needs a source that states them in text
  (circuit papers, open clone code), or a decision to tune by ear.

## Steps
1. Settle the open items.
2. Shared kit (src/2sl_kit.py + kit JS templates) from stab's helpers.
3. Pattern engine in JS with tests, against patterns.md.
4. gen~ voices: BD, SD, RS, CP, CH/OH first; toms, crash, ride after.
5. Pages, displays, presets; README with every choice cited, like stab's.
